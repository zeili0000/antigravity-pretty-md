    Keyboard Shortcuts

    • Ctrl+K — Open All-Docs Library
    • Ctrl+F — Find in current document
    • Alt+← / Alt+→ — Navigate Back / Forward across links
    • ? — Toggle this Power-User Reference
    • Ctrl+S — Save file in Raw/Edit mode
    • Esc — Close any modal, popover, or find bar

    Interactive Reader Actions

    • Click any ## heading → Fold / unfold that chapter
    • Click any LaTeX formula → Copy raw TeX source
    • Click any Mermaid / Vega-Lite graphic → Zoom modal
    • Click checkboxes → Cross off items (saved locally)
    • Drag & drop any .md file → View immediately

    Supported Portable Markdown Standards

    Works with standard GFM + Obsidian syntax: YAML frontmatter (title, summary, date, tags), callouts (> [!NOTE], > [!TIP]-, > [!THEOREM], > [!LEMMA], > [!PROOF]-, > [!FLASHCARDS]), ==highlights==, <kbd>, footnotes [^1], ```diff, ```mermaid, ```vega-lite, ```flashcards, and ```quiz.
